{% load i18n %}{% comment %} Suggestions under a plain text field (a combobox): EcoSelect.attach(input, {url, results, enforce}) and EcoSelect.detach(input, clear), which returns the input. The field stays an ordinary .form-input (same height, focus and editing as every field); its list looks like the tag fields' dropdown. url gets ?q=…; results(data) turns its answer into names. With enforce, only a name from the list is kept: what doesn't match one when leaving the field is removed with a hint. Arrow keys, Enter and Escape work as in a select. {% endcomment %}
